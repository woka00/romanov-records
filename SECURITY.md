# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use
GitHub's private vulnerability reporting for this repository, or contact the
repository owner privately through the GitHub profile.

Include the affected endpoint or component, reproduction steps, expected
impact and any suggested mitigation. Reports involving real customer data must
contain the minimum information necessary to reproduce the issue.

## Supported version

Only the current `main` branch is supported. Production secrets, database
contents and administrator credentials are not part of this repository.
